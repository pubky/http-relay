# Agent instructions

## Code

When writing, reviewing, or suggesting changes to code, follow
[readable-code](https://github.com/SeverinAlexB/readable-code/blob/main/skills/readable-code/SKILL.md).

## Issues and pull request descriptions

When writing an issue or a pull request description, follow
[technical-writing](https://github.com/SeverinAlexB/technical-writing-skill/blob/main/SKILL.md).
Write for developers in this repository who aren't familiar with the codebase.

Exception: for Critical security findings, keep the public pull request neutral.
See [Fix a Critical finding](SECURITY_REVIEW.md#fix-a-critical-finding).
